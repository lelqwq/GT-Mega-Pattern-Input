# GT Mega Pattern Input

GTNH 2.9.1 的 GT 附加模组，为 AE2 样板输入仓提供更大容量。

## 版本要求

| GTNH | 模组版本 |
| ---- | -------- |
| 2.9.1 | 1.3.0+ |
| 2.9.0 及更早 | 不支持 |

## 安装

1. 关闭客户端与服务端，备份存档。
2. 将 `gt-mega-pattern-input-<版本>.jar` 放入两端的 `mods/` 目录。
3. 同一 `mods/` 目录只保留一个版本，客户端与服务端必须一致。

## 依赖

由 GTNH 整合包提供，无需单独安装。

## 构建

```bash
./gradlew build
```

## 说明

个人自用模组，不提供官方支持。
